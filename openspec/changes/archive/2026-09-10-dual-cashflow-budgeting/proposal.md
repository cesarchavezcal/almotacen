# Proposal: Dual Cash Flow & Zero-Based Budgeting Engine

## Why
Users struggle with personal finance because existing tools force an unnatural compromise: passive trackers (Monarch) show where money went without constraining future spending, while envelope tools (YNAB) create immense friction at point-of-sale logging.

## What Changes
1. Core dual-sided ledger engine calculating both real liquid cash and virtual envelope balances in atomic integer-cents math.
2. Point-of-sale quick expense capture modal for sub-3-second entries.
3. Reactive cash flow dashboard combined with a zero-based envelope budget planner.
4. Local-first SQLite persistence with offline-ready sync markers.

## Target Impact
Enables frictionless on-the-go transaction entry with zero-based intentional allocation.
