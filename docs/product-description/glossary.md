# Canonical Glossary

| Term | Definition |
|---|---|
| **Ready to Assign** | The pool of unallocated liquid income awaiting assignment to budget envelopes. In zero-based budgeting, this must reach $0.00. |
| **Envelope Category** | A named spending or savings bucket with an allocated monthly amount, consumed activity, and remaining balance. |
| **Transaction** | An atomic financial record recording amount, date, payee, associated account, and envelope category classification. |
| **Cash Flow Delta** | The real-time difference between total monetary inflows and total outflows for a designated billing or calendar month. |
| **Liquid Account** | A registered financial holding container (e.g. Checking, Savings, Cash) that contributes directly to available spending power. |
| **Reconciliation** | The verification checkpoint confirming that internal ledger balances match physical bank statement balances. |
